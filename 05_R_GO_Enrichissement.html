📊 Vue d'ensemble

🎯 Objectif : Analyse d'enrichissement Gene Ontology (GO) pour identifier les processus biologiques surreprésentés dans les gènes différentiellement exprimés (DEGs) des interneurones GABAergiques VIP entre patients schizophrènes et contrôles.

Type Cellulaire

Seuil FDR

0.05

🔬 Méthodologie

  • Package : clusterProfiler (Bioconductor)
  • Base de données : org.Hs.eg.db (Homo sapiens)
  • Ontologie GO : Biological Process (BP)
  • Méthode d'ajustement : Benjamini-Hochberg (BH)
  • Seuil q-value : < 0.05

🔬 Code R - Script d'Enrichissement GO

📄 Fichier : 05_R_GO_Enrichissement.R
🎯 Type d'analyse : Gene Ontology Enrichment Analysis (GOEA)
🧬 Gènes analysés : DEGs des interneurones VIP GABAergic cortical (FDR < 0.05) 
library(clusterProfiler)
library(org.Hs.eg.db)

# Charger les DEGs VIP (374 gènes)
vip_degs <- read.csv("C:/Z/M2_AIDA/transcriptomics_project/data/exports/DESeq2_Results/VIP_GABAergic_cortical_interneuron_DESeq2.csv")
sig_genes <- vip_degs[vip_degs$padj < 0.05, ]

# Enrichissement GO
go_results <- enrichGO(
    gene = rownames(sig_genes),
    OrgDb = org.Hs.eg.db,
    ont = "BP",  # Biological Process
    pAdjustMethod = "BH",
    qvalueCutoff = 0.05
)

# Top 10 termes
dotplot(
  go_results,
  showCategory = 10,
  orderBy = "x",
  title = "Enrichissement des processus biologiques (GO) dans les interneurones GABAergiques VIP – SCH vs CTRL"
)

✅ Fonctionnalités du script

  • Chargement des résultats DESeq2 pour les interneurones VIP
  • Filtrage des gènes significatifs (padj < 0.05)
  • Analyse d'enrichissement GO (Biological Process)
  • Visualisation dotplot des 10 termes GO les plus enrichis

🔍 Interprétation

🧬 Analyse d'Enrichissement GO

L'analyse d'enrichissement Gene Ontology permet d'identifier les processus biologiques surreprésentés parmi les 374 gènes différentiellement exprimés dans les interneurones GABAergiques VIP. Cette approche révèle les voies fonctionnelles potentiellement perturbées dans la schizophrénie au niveau de ce type cellulaire spécifique.

⚠️ Note Technique

L'avertissement concernant l'argument by = "Count" dans barplot() indique une incompatibilité de paramètre avec la version de clusterProfiler utilisée. Cela n'affecte pas les résultats de l'enrichissement GO lui-même, mais peut affecter la personnalisation de la visualisation. Il est recommandé d'utiliser dotplot() à la place pour une meilleure compatibilité.
